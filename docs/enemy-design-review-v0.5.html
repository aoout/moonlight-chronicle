是我漏读了一个文件得出的。

向你说清楚：小怪有独立技能系统（src/domain/enemies/skills.ts），10 只全有专属技能，前 v0.3/v0.4 只读了移动层（behaviors/）就下了「6/10 直线追同质化」的结论——错得离谱。v0.5 全面修正。

纠

v0.3/v0.4 的两个核心判断是错的，撤回：①「6/10 小怪行为同质、只有 4 只标杆」——错误。10/10 小怪都有专属技能（grub 酸液三连 / rat 撕咬扑击 / armored 重踏震地 / wing 羽毛弹+俯冲 / shadow 影雾闪现+流血 / giant 巨拳砸击……）；②「abilities 行为类承诺 0/3 兑现」——错误。wing「飞行」= 俯冲抓击、shadow「闪现」= 影雾瞬移 + 流血 DOT（bleed 系统真实存在），都兑现了。

01

修正后的真相：小怪技能系统完成度很高。10 只小怪拥有 10 套技能，其中 5 套带「前摇（skillP）+ 预警（flash）」双阶段——rat 0.28s 前摇扑击、armored 0.5s 重踏、giant 0.7s 巨拳、wing 0.55s 俯冲。spitter 有预判射击，shadow 的闪现还带 3 秒流血 DOT。这套行为系统的设计质量，比 v0.3 报告描述的整整高一个档次。

02

修正后的同质化判断：双层同质，不是行为同质。真正的重复在两处——① 移动层：6 只共用 chaseMove（直线追）；② 近战爆发模板：grub / rat / armored / giant 共用「近身读条 → 前摇 → 范围爆发」同一个技能骨架（skillT → skillP → flash → meleeHit），差异只是半径 / 倍率 / 前摇时长。技能层是异构的，但 4 只近战怪打的是同一个「读条」节奏。

03

视觉可读性诊断不受影响，依然成立：敌我弹共用白核、颜色冲突、优先级不编码——这些基于渲染层代码，与小怪技能无关，v0.5 保留。

修正后的同质化判断：双层同质

同质层 A · 移动（6 只）

grub / rat / armored / giant / splitter + 召唤物共用 chaseMove

6 只的「追你」动作完全一样（直线朝玩家），压迫感节奏雷同。但注意：v0.5 修正后，移动同质 ≠ 行为同质——这 6 只的技能各不相同（酸液 / 扑击 / 重踏 / 巨拳 / 分裂）。移动同质影响的只是「接近感」，技能层已经把它们区分开了。

修正方向：给 chaseMove 家族加「移动个性」（grub 蠕动间歇 / armored 缓步 + 转向慢 / giant 震地缓行），把压迫节奏也分开。
同质层 B · 近战爆发模板（4 只）

grub / rat / armored / giant 共用「读条爆发」骨架

四只近战怪的技能骨架完全相同：skillT 冷却 → skillP 前摇 → flash 预警 → meleeHit 范围判定。差异只是半径（34/92/140）、倍率（1.5×/1.9×/2.2×）、前摇（0.28s/0.5s/0.7s）。玩家面对四只怪打的节奏是同一个「看闪避读条」——这是技能层的第二层同质，v0.3 完全没看到（因为没读技能层）。

修正方向：打破模板——把 rat 改成「连续两段扑击」、armored 改成「盾牌顶推 + 反伤」、giant 改成「多段震地波」而非单发读条。让 4 只近战怪节奏互不相同。
异构群 · 机制动词（6 只）

charger 冲锋 / spitter 预判 / bomber 自爆 / wing 俯冲 / shadow 闪现 / splitter 分裂

这 6 只的技能动词互不重复：冲锋、预判射击、接触自爆、俯冲、瞬移、分裂。v0.5 修正后的真实结论：技能层的异构度远超 v0.3 的判断——10 只怪里 6 只有独特动词，剩下 4 只共用爆发模板。系统底子比之前认为的好得多，问题收窄为「近战四只的节奏同构」+「移动层雷同」。

下一步：把 4 只近战爆发怪的节奏差异化，而不是再造新怪。新怪继续堆，只会加重移动层和爆发模板的重复。

Boss 的三个结构性问题（v0.5 保留）

问题一 · 无阶段转换

Boss 从入场到死亡只有一套节奏：attCd 循环出招。血量 30% 只有视觉变红，没有行为变化。「太弱无聊 / 太强挫败」的结构根源在此。

修：血量 30% 狂暴——attCd ×0.75 + 追加新技能 [PLACEHOLDER]。狂暴前必须播演出，可预期。

问题二 · 终焉是「全技能混合」

终焉把 4 技能全叠，一次出招 ≈ 60+ 弹。它没有自己的动词，只有别人的技能的合集——同质化最高的一位。

修：给终焉独有机制（蚀月相位：30% 血切换弹幕相位，每相位 ≤2 类威胁），让终焉战变成「读懂机制」。

问题三 · 三威胁无解帧

多数技能 = 全向弹 + 追踪球 + 地面封锁三件套。追踪要绕圈甩、地面要提前走、全向要侧移——三者同时出现时没有「安全移动」的帧。

修：单次出招同时威胁类型 ≤ 2 [PLACEHOLDER]；追踪球上限 4，lockT 保持可甩差异化。

好消息 · 三只已有「招牌动词」

战车（冲撞 ×3 转向追踪）、剑豪（三连斩横扫）、魔龙（吐息 + 双侧绕后）——机制身份已成型。方向正确，其余 7 位补上。

行动：为每位 Boss 写一句「玩家学到的动词」，其余 7 位逐一补齐。
