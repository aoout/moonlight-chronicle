Moonlight Chronicle · Progression Design

当月光照到尽头，
守月人为什么还要再出征一次？

《蚀月远征》终局进度设计提案。不是加内容，是把「打完这局」变成「下一局更强」的回路接上。

核心诊断

游戏不缺可玩性，缺一条跨局货币回路。现在四本账（关卡解锁 / 成就 / 图鉴 / 诅咒精通）全是死账本——解锁完的那一刻就失去意义，没有任何东西把单局产出变成局外资产。深度系统是纯惩罚堆叠，风险没有对偶回报，打到最高深度自然无事可做。

现状：20 夜终焉 · 深度 0–9+
跨局进度：仅 1 个数字（unlocked）
跨局货币：无
提案：6 方向 · 3 阶段落地

为什么「打完就停」：四个病灶

不是玩家腻了，是系统在终点处断了线。四个问题按严重程度排：

P1

没有跨局货币

金币经济完全局内闭环（商店局内、gold 存局内档）。单局产出的唯一去向是「这局变强」——它没法变成「下局更强」。这是最根本的断点。

证据：save.ts 只持久化 unlocked + 局内 run；statState.gold 从不出局
P2

深度是纯惩罚，无对偶回报

深度 = 随机诅咒（debuff）+ 敌人缩放。风险堆得很足，回报却只有潮锚武器和侵蚀两条窄缝。玩家没有「为什么值得冒险」的理由，赌徒不上桌。

证据：enemyScale 双维缩放 + curse 全 debuff；深度奖励仅 2 处（潮锚 / 侵蚀）
P3

成就 / 图鉴 / 精通是死数据

三本账只进不出：没有任何 source 连向 sink。玩家做完一个目标，得到的是一句「解锁了」，而不是一把打开下一个目标的钥匙。

证据：AchievementSystem 解锁仅 emit 事件；零 reward 发放
P4

深度选择无决策感

诅咒是随机抽 3 选 1，玩家被动挨打；深度 5 双契可能抽到完全克制的组合。惩罚不可预期 → 玩家不敢冲高深度 → 垂直进度提前封顶。

证据：curse_pick 随机抽 3；无自选、无倍率、无预判

A

蚀月回响 · 声望货币与月契树

ECHO OF THE ECLIPSE — PRESTIGE CURRENCY & PERMANENT TREE
FUN HYPOTHESIS「打完这局的回响，变成下一局开局就摸得到的力量」——单局强度（等级/武器/祝福）和跨局强度（月契树）分成两条正交的轴，任何一局都不会白打。

机制：通关结算（死亡或通关 20 夜）时，按通关夜数 × 深度 × 契约倍率结算「蚀月回响」。回响在月契面板兑换 3 条永久升级树——月刃（攻击）、月魄（生命）、月运（金币/经验），每树 15 级、每级 +2%，总加成封顶 +30%。回响同时解锁新武器条目、新起始祝福（与 C/E 共用 sink）。

为什么这样设计：这是 Vampire Survivors 验证了五年的 meta loop——玩家每次死亡都被「买得起下一点」安慰，单局挫败感被跨局进度对冲。关键是回响必须和金币严格分离：金币买局内强度、回响买局外强度，两条轴不打架，局内经济不被 meta 通胀污染。

变量草案值Rationale
通关 20 夜基础回响50≈ 打 4 局可点出第一棵树的第 3 级，10 分钟内见第一个「明显变强」
每深度 +15深度 9 基础 185 → 让「冲深度」永远比「重复低深度」赚
每契约 ×+25%与 B 联动；3 契封顶 ≈ ×1.75
月契树总加成≤ +30%硬 cap。超过则低深度变无双，垂直进度失去意义
满树总成本~600 回响约 8–10 局深度 5+，两周日活量级 [PLACEHOLDER]
回响获取衰减同深度重复递减 20%/局防止「刷最肥的一档」；衰减到 0 后换深度才有收益
交互风险：通胀是头号杀手——月契树给太多，深度 0 变成无双，垂直进度全线崩盘。对策：总 cap + 每级边际收益递减（前 5 级 +2%、后 10 级 +1.5%）。另外回响货币一旦存在，成就必须开始发回响（否则成就继续死着），P3 的账要一起还。
实现成本：中（新账本 + 结算 UI + 升级树面板）
新增文件：~5（echo ledger / tree config / settle / panel ×2）
可玩性增益：★★★★★

B

蚀之契约 · 从随机挨打到自选赌注

CONTRACT OF THE TIDE — SELF-CHOSEN CHALLENGES
FUN HYPOTHESIS「惩罚是我自己选的，输了认，赢了是我赚」——把「随机诅咒」改成「契约台自选 modifier」，玩家的挫败感来自赌输而非被系统整，回响倍率把赌注变成诱惑。

机制：开局进「契约台」：展示全部 9 种诅咒作为可勾选的契约（可叠加），每种标注回响倍率。深度不再隐式决定惩罚，而是深度 = 最低契约数门槛（深度 5 至少 2 契）。原有「精通诅咒 → 蚀之回响恩惠」保留：精通 = 白嫖恩惠层，契约 = 主动赌注层，两层叠加、互不覆盖。

顺手修掉的 bug：现有随机 3 选 1 可能抽到完全克制的组合（比如双 debuff 叠加攻速归零）。自选之后玩家永远可以避开「必死组合」，把死亡原因从「被系统坑」改成「我赌输了」——这在玩家心理账户上是两笔完全不同的账。

交互风险：最优解固化——玩家发现「移速 -40」对远程 build 无所谓，就会永远勾它刷倍率。对策：倍率与 build 无关化不可行（做不到完美），但可让每局倍率取「所勾契约的乘积 + 同契约重复衰减」，并接受「聪明玩家找到最优」——那是 build 多样性问题，不是进度问题。
实现成本：低（curse 框架现成，改选择流程）
新增文件：~2（contract 配置表 / 契约台 UI 改造）
可玩性增益：★★★★☆

猎杀契约 · 让图鉴成为目标，而不是博物馆

HUNT CONTRACT — CODEX AS OBJECTIVE
FUN HYPOTHESIS「图鉴里那个空槽，是我下一局的理由」——每只怪物/Boss 变成可完成的狩猎目标，图鉴完成度从「记录」变成「进度」。

机制：图鉴每条目加两层目标——收录（见过一次，现有）+ 猎杀（累计击杀 N 只）。每完成 5 条猎杀目标 → 结算一次性回响奖励（+10），并与 A 共用 sink：全图鉴大师再给「蚀月巡礼」头衔与专属月相。Boss 条目额外生成每日通缉令：随机 1 位 Boss，当日击杀回响 ×2（每日 0 点刷新，本地时间）。

为什么每日通缉而不是每日挑战：通缉令不改变玩法规则，只改变「今天值得打谁」——它把「再开一局」的犹豫成本降到零，因为今天的目标是具体的、有死线的、翻倍的。这是签到系统该有的样子：给选择，不给压力。

交互风险：挂机刷猎杀。对策：猎杀计数只记「进入战斗后击杀」，且每日通缉只对 Boss 生效（Boss 无法挂机刷）。另一风险是图鉴完成度高的老玩家无处可猎——通缉令对 Boss 池全开，永远有目标。
实现成本：低（图鉴结构现成，加计数 + 结算）
新增文件：~2（hunt 目标表 / 通缉令调度）
可玩性增益：★★★☆☆
D
D

无尽蚀潮 · 终夜之后还有夜

ENDLESS TIDE — BEYOND THE FINAL NIGHT
FUN HYPOTHESIS「第 21 夜开始，敌人不再讲道理，而我要看看自己能活到第几夜」——把「通关」变成「开始」，进度上限从 20 变成无穷。

机制：通关 20 夜后不再强制结束，进入无尽蚀潮：敌人数值按外推曲线继续成长（stage > 20 时 hp/dmg 按每夜 +8% 指数外推，从 stage 20 的基线上），Boss 每 3 夜一个循环刷新，不再进商店（纯生存），玩家死亡时记录「最深夜数」与「无尽击杀数」进本地榜单。回响在无尽中按「每撑过 3 夜 + 1 档」继续结算，与 A 联动。

为什么它比「加 20 个新关卡」便宜且有效：新关卡要美术、要敌型、要 Boss 设计，是内容投入；无尽模式是让同一套机制产生无限目标——玩家的成就感从「通关」转为「超越自己上次的夜数」，这是排行榜型进度，维护成本趋近于零。

交互风险：回响刷取——挂机无尽白嫖回响。对策：无尽回响按「关卡数指数衰减」：前 3 夜正常，之后每夜 ×0.9，刷到 30 夜时回响率只有 10%。曲线重新外推要标 [PLACEHOLDER]，stage 20 的难度封顶值先测 20 场再说。
实现成本：低（去掉终焉结束 + 外推曲线 + 本地榜）
新增文件：~3（endless 曲线 / 榜单 / 结算扩展）
可玩性增益：★★★☆☆

E

月契书 · 看得见的身份进度

MOON OATH — IDENTITY PROGRESSION
FUN HYPOTHESIS「别人一看我的称号和月面，就知道我下过多深的渊」——用回响兑换可见身份资产，把进度变成社交货币。

机制：回响兑换四类身份资产——称号（结算界面 / HUD 展示）、头像框（存档同步界面）、月面涂装（月相按钮 / 加载图）、主题 BGM（局内配乐替换）。全部纯配置数据，解锁即永久。关键设计：每个高稀有度称号带解锁条件（如「深空之王」需深度 9 通关），条件不满足时不可用回响购买——保证称号的含金量，防止「回响多 = 头衔大」的通货膨胀。

定位警告：E 是奖励层，不是进度主轴。纯装饰进度在第二周就会失效（VS 的收藏品从不是留存主力）。它存在的意义是给 A/B/C/D 的产出一个看得见摸得着的出口，让回响有处可去——sink 补上了，货币才有价值。

交互风险：低。唯一要防的是「装饰解锁与回响解耦」——若称号只靠回响买，深度 9 玩家和刷子玩家会买一样的头衔，社交信号就贬值了。条件解锁是硬约束。
实现成本：低（纯配置 + 展示位）
新增文件：~2（oath 配置表 / 展示组件）
可玩性增益：★★☆☆☆（配角）

月相轮转 · 每天的世界不一样

LUNAR PHASE — DAILY ROTATION
FUN HYPOTHESIS「今晚是血月，货价翻倍，敌人也红了眼——今晚值得一试」——复用月相系统做每日全局 modifier，让「今天」成为打开游戏的理由。

机制：项目已有 moon_phase 配置（月相描述）。扩展为每日月相 modifier：8 种月相各配一个全局规则（如血月：敌人 +30% 但金币 +50%；新月：经验 +30% 但视野 -20%）。每天 0 点按本地月相轮转，HUD 与开局界面明示今日规则 + 今日目标（「血月夜：单局赚 800 金」），达成目标给小额回响。月相系统从此从「装饰描述」变成「每日内容轮播器」。

为什么放最后：F 是「新鲜感」层，它依赖 A 的回响做奖励出口，依赖 C 的每日通缉做节奏锚点。没有 A/C 的 F 只是数值浮动，玩家第二天就无感；有 A/C 的 F 让「每天打开看一眼今天什么月相」成为习惯。

交互风险：每日 modifier 若只有数值浮动，第三周开始麻木。对策：每个 modifier 至少改变一种「决策」（血月逼你激进抢钱、新月逼你贪经验冒险），而不是单纯加减——modifier 必须制造新决策，否则就是换皮数字。
实现成本：低（moon_phase 现成 + 规则表）
新增文件：~2（phase 规则表 / HUD 提示）
可玩性增益：★★★☆☆（依赖 A/C）
伍

落地路线图：先接回路，再开阀门

别一口气全做。三阶段，每阶段是一个完整可验证的闭环。

PHASE 1 · 最小闭环

A + B：货币与赌注

目标：任何一局都不白打
  • A 蚀月回响：结算货币 + 月契树（攻击/生命/金币三树）
  • B 蚀之契约：诅咒改自选 + 回响倍率
  • 成就补发一次性回响（还 P3 的旧账）
为什么先做这两个：A 是回路本身，B 是让回路有意思的阀门。没有 B，A 只是「更肝的解锁」；没有 A，B 只是「更爽的受虐」。两者合体才构成「自选挑战 → 回响 → 变强 → 更狠的挑战」——这是整个终局的地基。
PHASE 2 · 世界有目标

C + D：猎杀与无尽

目标：进度上限从 20 变成无穷
  • C 猎杀契约：图鉴目标化 + 每日 Boss 通缉令
  • D 无尽蚀潮：20 夜后无限 + 本地榜单
  • 月契树再开 1 条分支（武器解锁条目）
C 把已有的图鉴资产盘活（零新美术），D 给垂直进度一个无限上限。两个都是「现有结构 + 新目标」的低成本改造，Phase 1 的回响在这两层继续流动，经济不再淤塞。
PHASE 3 · 身份与新鲜感

E + F：身份与每日

目标：每天有一个打开游戏的理由
  • E 月契书：称号 / 头像框 / 月面 / BGM
  • F 月相轮转：每日 modifier + 今日目标
  • 本地榜单 → 可选：种子排行榜（跨设备）
E 是回响的装饰出口，F 是每日节奏。两者都依赖前两阶段的货币与目标系统才有意义——顺序反了，就是空中楼阁。
陆

系统交互矩阵：新增 × 现有

每个新系统与现有系统的交互先定性：intended（设计内）/ acceptable（可接受）/ bug（必须修）。提前暴露打架风险，是这条红线的例行公事。

交互对定性说明
深度 × 回响结算 INTENDED 高风险 → 高回响，深度的对偶回报补上了。这是整套设计的核心杠杆
诅咒精通 × 蚀之契约 INTENDED 精通 = 被动恩惠层，契约 = 主动赌注层，两层叠加互不覆盖。精通系统从「隐性」变「显性」
金币（局内）× 回响（局外） INTENDED 两条正交经济轴：金币买局内强度，回响买局外强度。刻意隔离，防 meta 通胀污染单局
成就 × 回响 ACCEPTABLE 成就补发一次性回响（旧账）；注意一次性发放量 ≤ 月契树总成本 20%，防一次性暴富
无尽模式 × 商店 BUG · 需设计 20 夜后必须停商店（纯生存），否则回响 + 无尽商店 = 无限变强的永动机。规则先行：终夜之后无集市
每日通缉令 × 无尽模式 BUG · 需设计 通缉 Boss 在无尽中反复出现 → 单局可刷多次通缉。对策：通缉令只在非无尽结算一次，或无尽中不触发通缉
月相轮转 × 契约台 ACCEPTABLE 月相 modifier 与契约叠加；风险是组合后难度不可预期 → 倍率 = 月相 + 契约的乘法，需 playtest 校验封顶

验证计划：先定义「坏掉长什么样」

没有失败定义的 playtest 等于没做。每个系统开测前，先把红线划好：

SIGNAL A

通胀失速

月契树满级玩家在深度 0 碾压（≤ 30 秒清空一夜）→ 垂直进度崩盘。

阈值：满树 vs 零树，深度 0 通关时间差 > 2 倍 → 砍 cap
SIGNAL B

契约无人问津

95% 玩家永远只勾同一两个契约 → 最优解固化，决策死了。

阈值：单契约使用率 > 70% → 重定价或重设计该契约
SIGNAL C

回响淤塞

玩家回响存量 > 3 棵满树成本 → sink 不足，货币变数字。

阈值：中位玩家回响存量达到满树成本的 150% → 开新 sink
SIGNAL D

无尽疲劳

无尽模式平均撑过夜数 < 23（只比终焉多 3 夜）→ 曲线太陡或奖励太薄。

阈值：中位数撑过 20 夜 + 2σ 内玩家撑 < 24 夜 → 放缓外推曲线
