# 蚀月远征 · 月之民碎片叙事圣经（Lore Bible）

> 本文档是《蚀之图鉴》全部武器/道具文案的**内部设计圣经**。
> 它不对外展示——玩家能看到的只有图鉴里那些互相矛盾的碎片。
> 写作原则只有一条：**作者知道的，要比写出来的多十倍。**

---

## 一、时代划分（叙事暗线，永不直接说出）

文案里不出现正式纪年，只用物证暗示时代归属。内部按四个时代组织：

| 时代 | 别称 | 状态 | 关键物证 |
|------|------|------|----------|
| 辉月纪 | "有光的日子" | 月之民自星海抵达，在月面安居 | 银湾、童谣、猎鹰之瞳 |
| 蚀潮纪 | "月生病了" | 蚀斑出现，蚀物诞生，蚀理学派兴起 | 透镜、星图、蚀星连弩 |
| 讨伐纪 | "猎月之年" | 曦月帝国讨伐蚀物，一度胜利 | 陨星、战车、断月之契 |
| 神裁纪 | "赎罪的年代" | 月灵信仰兴盛，神殿、血祭、审判 | 圣裁光柱、荆棘王冠、典仪书 |
| 残月纪 | "月背之世" | 月之民几乎死绝，残民退守月背，守月人出世 | 守月之约、你的月亮、远征手记 |

**关键设定：月亮背面的残民从不在文明档案里出现——官方史书只写到"月之民皆殁"。守月人是"历史上不存在的人"。**

## 二、核心母题（三条暗线，贯穿全部文案）

### 1. "看见"即是侵蚀的入口 —— 观测者母题
- 蚀理学派最重要的发现：**蚀斑在"被记录"的瞬间生长加速**。月面最早的蚀斑，恰好出现在第一张月面详图绘成的位置。
- 图鉴本身就叫《蚀之图鉴》——**你每记录一件蚀物，都在完成一次观测**。
- 神裁教团的"净月审判"宣称：看月亮看得太久的人，会被月亮看见。

### 2. "破晓"是一个谎言 —— 归乡母题
- 月之民自星海而来，母星早已不可考。但他们的语言里保留着"破晓"、"鹰"、"海"、"泥土"这些**月亮上不存在的事物**。
- 神裁纪严禁谈论"另一颗星"——那是"不忠的想象"。所以"破晓"成为所有禁忌词汇里最危险的一个。
- 月亮没有黎明。可守月人的武器里有一把叫"破晓之辉"。

### 3. "月灵"是否存在 —— 信仰母题
- 神裁教说：月灵是月亮的意志，惩罚不虔诚者。
- 蚀理学派说：那是蚀潮的回声，被误认成了神明。
- 守月人不表态。守月人的誓词里没有月灵，只有月亮本身。

## 五·五、深层档案 · 记手录（解锁机制的世界观化）

月背档案的墨迹是「记手」的——它认得持握者的手。

> 器识其主。同一件器物被同一只手拿起十次，深一层的字才会从纸下渗出来。

- 每在商店「选取」一次武器/道具，记手录便添一笔（跨局累计）。相伴十次，深层字迹显现。
- **深层字迹多是不愿被看见的**：蚀理院遗书的续页、被红墨划去的批注、写给「你」的最后一页。浅层是"可以被记录的"，深层是"只能被记住的"。
- 呼应网：月辉回刃"回旋刃会记住投掷者的手"、穿透符文"箭头读到名字"、猎月之环"蚀物叫得出我们的名字"——月亮与器物，都在认手。
- 图鉴详情中深层未解锁时，展示设定原文与进度「与此物相伴 N / 10 次」。

## 六、写作规范（魂系碎片化六大铁律）

1. **绝不直说因果**。"因为……所以……"是禁语。只给物证、只给行为、只给情绪残留。
2. **来源互相矛盾**。同一事件至少两种说法，且都不完整。
3. **关键页永远缺失**。最重要的信息出现在"缺页"、"烧毁"、"涂抹"上。
4. **物品写侧面**。不写"这是帝国末代皇帝的剑"，写"剑柄的纹章被磨平了，仍有人对着它行礼"。
5. **克制用词**。多用短句、名词、留白；少用形容词堆砌；不说"悲惨""伟大"这类评判词，让读者自己得出。
6. **互文呼应**。武器的 lore 提到的战役，道具的 lore 用另一个来源呼应同一件事，但细节对不上。

7. **绝不替读者指出悬念**（用户校正，2026-08-06）。「是谁写的？」「没人知道」「不详」「旁注：谁」——这些都是在告诉读者"注意，这里有谜"，等于把谜的气球戳破，读者反而不好奇了。残缺要**自然呈现**：话说到一半就停，让读者自己起疑。问号只属于故事内角色的困惑与情绪（童谣的孩子、遗书的学徒、血字批注者），绝不属于档案整理者。

**去 AI 感检查**（每段必查）：不解释、不总结、不用"不禁/忍不住"、不写完美对仗句、每段必须有"缺失感"；**通读一遍，凡是"作者跳出来引导读者注意线索"的句子，删。**

## 八、实现说明（工程侧）

- 文案存放在 `src/config/lore.json`，与既有 JSON 数据分离，`weapons.ts` / `items.ts` 加载时按 id 合并。
- 结构：`{ "weapons": { "<id>": [ { "src": "来源", "text": "正文" } ] }, "items": { ... } }`
- **分层**：每个条目两条碎片——第 1 条浅层（默认可见），第 2 条 `"deep": true`（需相伴十次）。
- **记手录**：`src/infra/persistence/hands.ts`（localStorage key `eclipse_hands_save`），`commands/shop.ts` 购买武器/道具时 +1。
- 图鉴详情面板：点击已解锁卡片展开详情，展示名称/属性/公式 + 相伴次数 + lore 碎片列表；深层未解锁显示设定原文与进度，dev 模式深层直显。
- 未解锁条目不展示 lore（保持"见过的才记得"的解锁逻辑）。
