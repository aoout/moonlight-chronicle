Moonlight Chronicle · Boss Appearance v0.7

外观不是皮肤，
是 Boss 的世界观立像。

十位蚀月之主，每位的外形都从「它叫什么、它打什么弹幕」里长出来——潮汐兽有浪脊，战车有蚀轮，终焉就是月亮本身。SVG 立像 + 设计语言，一眼看懂设定。

意象 · 它是什么

每位 Boss 一个核心意象：潮汐之魂 / 孕育之躯 / 碾压之械 / 月神王者 / 幽灵咒师 / 月白剑客 / 天空霸主 / 雷暴之枭 / 凝视之巢 / 蚀月本体。

形状 · 它长什么样

形状语言来自名字：浪脊背甲、蚀轮、月冠、兜帽雾体、熔岩鳞、雷羽翼——玩家看剪影就知道是谁。

材质 · 它由什么构成

材质表达来源：潮水、蚀壳、月光、影雾、熔岩、深渊——身体的材质就是它的出处。

动效 · 它怎么活着

动效表达性格：潮汐呼吸、卵囊搏动、车轮碾转、月相轮转——静止的 Boss 立像也会「活」。

呼应 · 弹幕即投射

弹幕是外观的投射：浪花弧片弹 = 背脊浪纹、蚀月环 = 终焉外环——打出去的弹和立像同源。

立像：10 座（SVG 可动）
设计语言：5 层
动效：12 种
配色系统：10 套

十位蚀月之主 · 立像图鉴

每座立像都是动态 SVG——悬停可暂停（尊重 reduced-motion）。设计要素逐层标注。

01

蚀潮巨兽

BEHEMOTH · 潮汐之魂
第六夜 · 蚀潮自月背翻涌而出

设定：潮汐的化身——它不是「住在潮里的兽」，它就是潮本身。身体由层层浪脊堆叠，漩涡眼凝视着月背，白沫沿身体边缘起落，每一次呼吸都是潮汐的一次涨落。

意象潮汐之魂：身体即浪潮
形状浪脊背甲（三道波峰）/ 漩涡眼 / 水浪鳍鬃
材质水纹渐变（青蓝→深蓝）+ 浪花白沫边缘
动效全身呼吸明暗 + 鳍鬃摆动 + 尾迹潮水流动
呼应浪花弧片弹 = 背脊浪纹的投射；弹幕呼吸变速 = 它呼吸的节奏
02

潮噬之母

TIDE MOTHER · 孕育之躯
第六夜 · 潮噬之母分娩蚀潮

设定：孕育蚀潮的母体。巨大的腹部近乎透明，腹中卵囊清晰可数、随心跳搏动——你看到的每一颗卵，都是下一波弹幕的胚胎。触手既是产卵器也是捕食器，低伏的头颅从不高昂，因为它所有存在感都在腹中。

意象孕育之躯：腹即子宫，卵即弹药
形状透明卵腹 / 产卵触手 ×2 / 壳纹背甲
材质腐殖青绿（青→墨绿）+ 卵膜半透明 + 卵白光泽
动效腹中卵搏动（脉动节奏）+ 触手摆动 + 背甲呼吸
呼应卵囊弹 = 腹中卵的直接投射；卵囊会裂，腹中卵也终将孵出
03

蚀壳战车

ERODE CHARIOT · 碾压之械
第六夜 · 蚀壳战车碾过月面

设定：被蚀壳驱使的战争机械——没人知道壳里是什么，只知道它碾过月面时，蚀纹沿着甲片蔓延。双蚀轮是它最醒目的身份：轮辐开裂、锈橙渗出，每一次碾转都在大地留下灼烧的轨道。

意象碾压之械：壳里无主，轮即意志
形状双蚀轮（裂纹环）/ 层叠蚀甲 ×4 / 巨角撞器
材质钢蓝蚀壳 + 锈橙蚀纹（金属被蚀的斑驳）
动效双轮反向碾转 + 甲片呼吸翘动 + 车头警示灯闪烁
呼应轮辐弹 = 蚀轮的凌空投射；冲撞 = 车身碾压的动作
04

噬月君主

MOON LORD · 月神王者
第十二夜 · 君主亲临吞噬月辉

设定：吞噬月辉的王者——长袍拖地三尺，袍缘镶着月相齿纹，头顶弯月冠，斜持月刃剑。它不奔跑、不咆哮，只是走到你面前，月亮就暗一分。它与巫王不同：巫王低语诅咒，君主只是挥剑，而剑光落处，月相改变。

意象月神王者：威严的静态压迫
形状月袍（拖地 + 月相齿缘）/ 弯月冠 / 月刃剑
材质月光紫袍（紫→深紫）+ 金饰 + 月轮背光
动效袍面星点流动 + 月冠浮沉 + 剑光呼吸 + 月轮辉光
呼应月相月刃弹 = 剑光的投射；弹幕数量随月相 = 背后月轮的状态
05

月影巫王

MOON WRAITH · 幽灵咒师
第十二夜 · 月影巫王低语蚀咒

设定：低语的咒师——兜帽下没有面容，只有两团咒火。身体是影雾凝聚的半透明存在，符箓绕身旋转，法杖悬空不落。它从不逼近你，只是飘浮、低语、施咒——你中咒的时候，它甚至没有转身。

意象幽灵咒师：飘浮的诅咒本身
形状兜帽雾体（无脸）/ 咒火双瞳 / 符箓环 / 悬空法杖
材质影雾半透明（紫雾）+ 咒火鎏金
动效雾体呼吸飘动 + 符箓环旋转 + 咒火闪烁 + 法杖浮沉
呼应符箓弹 = 身周符文的投射；蓄力加速 = 咒语引导的过程
06

断月剑豪

MOON SWORDSMAN · 月白剑客
第十二夜 · 断月之刃划过月辉

设定：三位十二夜之主中唯一「利落」的存在。束发、长衣、单刃——衣摆的边缘就是刀气的形状，蓄力时刀身泛起月白。它不施咒、不召唤，只是收刀、出刀、收刀，三连斩快-快-慢，是武道，不是巫术。

意象月白剑客：静如止水，动如断月
形状束发（红带）/ 刀气衣摆 / 月牙单刃 / 低眉
材质月白绸缎（白→淡紫）+ 银白刃 + 一点红
动效衣摆双段飘动 + 刀身蓄力发光 + 束发带飘 + 刀光残影
呼应刀气弧弹 = 衣摆边缘的斩出；快-快-慢节奏 = 收刀-出刀的身位
07

裂空魔龙

DRAGON · 天空霸主
第十八夜 · 魔龙撕裂穹顶降临

设定：撕裂穹顶的天空霸主——翼膜是撕开的夜空，龙鳞是流动的熔岩裂纹，弯角如蚀月、口含火光。它俯冲时翼展遮住整片月面，吐息时火光从喉口倾泻。与巨枭的「雷」不同，魔龙是「火」的纯粹暴力。

意象天空霸主：翼即苍穹之裂
形状裂空双翼（翼膜火纹）/ 熔岩鳞裂纹 / 蚀月弯角 / 尾焰
材质绯红龙皮 + 熔岩裂纹（橙→红）+ 暗黑翼膜
动效双翼摆动 + 熔岩纹脉动发光 + 口火闪烁 + 尾焰
呼应泪滴龙焰弹 = 口火的迸出；翼展 V 弹 = 双翼扇出的方向
08

蚀雷巨枭

STORM OWL · 雷暴之枭
第十八夜 · 蚀雷巨枭撕裂雷云

设定：雷暴的化身——展开的双翼就是雷云，翼羽边缘拖着电弧，双目是两颗雷核，眨动之间放电。它不吼叫，落雷就是它的语言：成行成列的雷在战场织成网格，而它悬在雷暴中心，像风暴本身。

意象雷暴之枭：翼即雷云，目即雷核
形状展翼（闪电羽纹）/ 雷核巨目 / 爪握雷光
材质电蓝雷云（蓝→深紫）+ 白电弧 + 鎏金雷光
动效双目放电闪烁 + 翼羽电弧脉动 + 双翼起伏
呼应雷羽弹 = 振落的翎羽；落雷网格 = 双目放电的方向
09

深渊巢母

ABYSS MOTHER · 凝视之巢
第十八夜 · 深渊巢母孵化万噬

设定：深渊本身在孕育。它的身体是层层内收的口器，一圈比一圈深，巢壁探出无数眼柄——每一只都在看你。酸液从触须滴落，骨刺如獠牙环立。与潮噬之母不同：潮母孕育于水，巢母孕育于深渊；潮母的卵看得见，巢母的凝视你躲不开。

意象凝视之巢：深渊的每一层都在看你
形状同心口器（三层内收）/ 眼柄复眼 / 酸触须 / 骨刺
材质深渊暗红（深→红紫）+ 酸液青绿 + 眼白
动效口器缓慢开合呼吸 + 众眼眨动/脉动 + 触须摆动 + 酸液滴
呼应深渊之眼弹 = 巢壁凝视的投射；微追踪 = 「被看着」的压力
10

蚀月终焉

FINAL ECLIPSE · 蚀月本体
第二十夜 · 蚀月化身——终焉之潮

设定：终焉就是月亮本身——被蚀去一半的月面悬在夜空，蚀纹之外是暗，蚀纹之内是金核在呼吸。外环蚀月环缓缓旋转，缺口处亮着一点白光——那不是装饰，那是它留给你的唯一生路。血雨从云中坠落，它不看你，因为你就是它要吞噬的整个月背。

意象蚀月本体：它就是月亮，被蚀的月亮
形状蚀纹月面（半月缺口）/ 金核 / 环形山 / 蚀月外环 / 血雨云
材质蚀月金（金→橙→暗）+ 暗蚀 + 血雨绯红
动效月核呼吸脉动 + 蚀月环旋转（缺口转 = 生路转）+ 血雨坠落
呼应蚀月环弹 = 外环的抛出（缺口即生路）；三相轮转 = 月相被蚀的过程

动效语言：立像怎么「活」

十二种动效，每种对应一种性格。规则：动效必须服务于设定——潮汐兽呼吸、车轮碾转、咒火闪烁，没有一个是装饰。

动效参数用于性格表达
breath 呼吸scale 1→1.055 · 3.4s巨兽身体 / 潮母背甲 / 终焉月面活着的、有节律的存在
breath-f 急呼吸scale 1→1.055 · 2.2s潮母卵腹 / 终焉金核孕育/核心的脉动
rot 旋转360° · 9–16s战车轮 / 巫王符箓环 / 终焉蚀月环机械运转 / 咒法循环 / 天体的恒定
pulse 脉动opacity .65→1 · 2.6s君主星点 / 巢母小眼 / 魔龙熔岩纹能量的呼吸
flicker 闪烁opacity 1↔.35 · 1.8s巫王咒火 / 战车警示灯 / 魔龙口火 / 巨枭雷眼不稳定、危险、不可预测
