升级节奏是难题？
先别调数字，拆掉那条唯一的轴。

「升太快玩完、升太慢气馁」的根源，是把所有进度都押在一条轴上。这一版给解法、给维度、给规范。

01

节奏矛盾的正解不是选中间值，而是五根杠杆同时上：凹形成本曲线、横轴优先于纵轴、软上限衰减、目标锚定、多轴并行——最后一根才是治本的，前四根是让单轴别那么脆。

02

可玩内容 ≠ 只加局外升级。六个维度：横向新内容 / 重玩机制 / 比较进度 / 发现进度 / 熟练度 / 时间性。本轮新增 9 项提案，其中武器进化与武器熟练度是这游戏最缺的两块（13 把武器、无进化、无熟练度——机制满意但横向空间一直空着）。

03

月相是白捡的进度资产：8 相效果表已存在（满月 +25% 攻），玩家却看不见、没有目标。显性化 + 目标化，成本极低，每日节奏立刻有了。

壹

节奏难题的解药：五根杠杆，不是一根曲线

「升太快玩完 / 升太慢气馁」不是同一个问题——前者是内容耗尽速度问题，后者是挫败感反馈问题，一根曲线救不了两个人。逐根上杠杆：

01

凹形成本曲线CONCAVE COST · 甜点区 + 马拉松区

成本不线性，前段极便宜、后段指数贵。前 3 级一局半点完（甜点区：玩家立刻体感变强，满足感充值）；4–8 级线性（稳定推进）；9–15 级指数（马拉松区：慢，但那是留给长期玩家的，不是留给所有人的）。关键心理：没人要求你满级——满级是理论极限，不是通关条件。

结论：曲线的形状比曲线的长度重要。前 30% 的成本应该买到 50% 的收益。
02

横轴优先于纵轴WIDTH OVER DEPTH · 多树浅深 > 单树深挖

一棵树 30 级是错的，3 棵树各 10 级才对。「玩完」的感觉来自单一轴上的线性劳动——同一棵树上点第 28 级和第 8 级是同一件事的重复。横向多轴让玩家每换一条轴都经历一次「新东西」的兴奋。再加一层共鸣节点：攻击树 5 级 + 金币树 5 级同时达成 → 解锁特殊月契，逼玩家横向走而不是纵向刷。

结论：内容耗尽的本质是单轴重复。多轴交替，把「玩完」的定义推后三倍。
03

软上限衰减DIMINISHING RETURNS · 让满级不值得刷

收益分段递减：1–5 级每级 +2%，6–10 级 +1.5%，11–15 级 +1%，总加成硬 cap +30%。设计意图：第 15 级永远不值得专门去刷——玩家点完第 10 级自然转向其他轴，追求「满级」变成没有性价比的行为，纵向的尽头被从心理上移除。

结论：硬 cap 管通胀，软衰减管「刷满强迫症」。两个都要，缺一不可。
04

目标锚定ANCHORED PROGRESSION · 升级是深度的验货单

把每段升级显式绑定深度区间：「这 5 级攻击力，正好够从深度 3 上到深度 5」。玩家冲深度的心理从「这局会输吗」变成「我攒的力量该验货了」——输了也得到信息：还差两级，再打一局。挫败感被翻译成明确的下一步，这是治「冲深玩家气馁」的直接解药。HUD 或结算页显示「下一段升级将解锁：深度 5 舒适区」。

结论：气馁来自没有进度反馈。锚定让每一次失败都变成「还差什么」而不是「我不行」。
05

多轴并行PARALLEL AXES · 唯一治本的杠杆

前四根让单轴别太脆，但单轴再完美也脆——任何一根曲线的节奏总会和某类玩家错位。真正的解药是 4–5 条节奏各异的并行轴：货币树（周尺度，缓慢持续）、图鉴/猎杀（天尺度，中速收集）、挑战纪事（离散目标，随时有得做）、每日/周常（短频，天尺度）、身份（月尺度，长期沉淀）。玩家总有至少一条轴在推进，「没事做」的窗口被多轴填满——这就是下一章的框架。

结论：这一根才是治本的。前面四根优化单轴，这一根消灭「单轴决定成败」本身。

G1

武器进化 · 月蚀合铸

WEAPON EVOLUTION — FORGED BY ECLIPSE
FUN HYPOTHESIS「差一把武器就能合出那把传说中的月蚀之刃」——满级双武器合成进化武器，单局构筑有了明确的「追装备」目标。

为什么这是本轮最重的提案：类幸存者品类的招牌纵向目标，你的游戏居然没有——13 把武器、5 槽上限、满级 Lv10，但满级之后武器只是数字变大。进化 = 给「凑两把武器」制造目标，玩家为进化而选 build、为进化而买商店、为进化而冒险冲深度。

草案组合（6 对，覆盖 12 把，初始武器 moonRing 参与）：

  • moonRing + crossbow → 月光连弩（环绕月环 + 连射）
  • meteor + frost → 冰陨星（大范围冰爆陨石）
  • beam + shadow → 影光蚀刃（穿透光束 + 暴击溢出）
  • orbit + lance → 月环长枪（多环 + 突刺）
  • storm + nova → 雷暴新星（弹幕 + 核爆）
  • phantom + tideAnchor → 深潮幻影（分身 + 深度倍率，吃深度对偶）

进化武器占 1 槽、自带独立图鉴条目与熟练度轨道（与 G8 联动），且进化不可逆——决策感：合了就没有回头路。

风险：数值成本高（6 把新武器 = 美术 + 公式 + 图鉴）。对策：先做 3 对（月光连弩 / 冰陨星 / 雷暴新星），验证「为进化而玩」的假设成立再补齐。另一风险：进化后 5 槽回收（原两把消失）导致中期 DPS 真空——进化武器的首级数值要覆盖两把满级之和，否则是负提升。
实现成本：中-高（新武器 ×6 + 合成 UI + 图鉴）
维度：横向新内容
进度感贡献：★★★★★（单局目标 + 图鉴条目 + 熟练度轨道）
G2

月相显性化 · 把白捡的资产亮出来

LUNAR PHASE MADE VISIBLE
FUN HYPOTHESIS「今晚满月，攻击 +25%——今晚是冲深度的日子」——月相效果表已存在，玩家看不见，等于没有。

事实：MOON_EFFECT_DESCS 已有 8 相完整效果（新月闪避 +25%、满月攻击 +25% 暴伤 +25%……）且按现实月相自动轮转。但玩家在局内看不到今天什么月相、有什么效果——一个每天在变的全局 modifier 白白躺着。

机制：① 开局界面 + HUD 明示「今日月相 · 满月 · 攻击 +25%」；② 特定月相触发稀有事件（血月出「蚀月精英」，掉双倍回响，与 A 联动）；③ 月相成为计划工具：玩家学会「等满月冲深度、等新月打无伤成就」——月相从装饰变成玩家的决策输入。

风险：几乎无。唯一注意：月相效果与 B 契约叠加后可能超预期（满月 + 蚀牙锋利 × 高阶深度）——倍率乘法封顶需 playtest，这是唯一要盯的点。
实现成本：极低（HUD 显示 + 事件钩子）
维度：横向新内容
进度感贡献：★★★☆☆（但成本近乎为零，性价比之王）
G3

远征纪事 · 限制 run 收集

EXPEDITION CHRONICLE — CONSTRAINT RUNS
FUN HYPOTHESIS「这张纪事卡还差最后一格」——把散落的成就挑战系统化成 3×3 纪事卡组，完成一张点亮一格。

机制：现有成就里已有大量「单局限制」素材（无伤之夜、90 秒 Boss、仅初始武器、一命……），把它们结构化：每张纪事卡 = 一种限制 run（如「孤月：仅 moonRing 通关终焉」），3×3 为一组，完成一行/一列解锁一枚「月契徽记」（回响或身份资产，与 A/E 共用 sink）。全组完成解锁隐藏称号。

与成就的区别：成就是「发生了就记一笔」，纪事是「预先承诺的目标」——玩家开局就知道这局要完成什么限制，决策感前置。且纪事卡 3×3 的格子视觉本身就是一个「还差一格」的收集进度条。

风险：限制 run 与随机性的冲突（「仅初始武器」可能商店刷不到理想辅助）。对策：纪事卡允许「契约豁免券」——已完成 5 次的诅咒可选择不抽（现成精通机制扩展），降低运气成分。
实现成本：低（成就机制现成，加结构化 UI）
维度：重玩机制
进度感贡献：★★★★☆
G4

流派图鉴 · 官方 build 挑战

ARCHETYPE CODEX — OFFICIAL BUILDS
FUN HYPOTHESIS「血月狂战流派，我还差两件专属道具」——官方定义 6 种流派，首通给「流派烙印」，驱动玩家换 build 玩。

机制：官方设计 6 种流派（如「蚀雾商人」：金币 build + 补货流；「新月刺客」：暴击 + 闪避流；「深潮守望」：深度倍率 + 生命流），每种 = 武器组合 + 道具清单 + 推荐契约。局内达成「流派配置 ≥ 80%」即判定流派 run，通关给「流派烙印」+ 回响加成 +15%。为什么有效：玩家最常问的是「这局怎么配」，流派图鉴把答案变成目标——参考与挑战一体化。

风险：流派判定过严则劝退、过松则无意义。阈值 80% 是 [PLACEHOLDER]；另一个风险是流派与随机商店冲突——商店可提供「流派关键件必出」保证（每流派 2 个核心件优先出现）。
实现成本：低-中（配置表 + 判定 + 图鉴 UI）
维度：重玩机制
进度感贡献：★★★★☆（让 build 多样性变成可收集的目标）
G5

蚀月占星榜 · 排行榜与每日种子

STARCAST RANKING — LEADERBOARD + DAILY SEED
FUN HYPOTHESIS「同一个世界，为什么他比我多撑了 6 夜」——排行榜是唯一「上限无限」的进度，总有人在你前面。

机制：三张榜——深度榜（深度 × 通关夜数复合分）、无尽榜（撑过夜数）、速通榜（终焉通关时间）。本地榜零成本先上；每日官方种子「蚀月占星」：所有玩家同一天打同一个种子世界，比成绩（种子系统 = 固定 RNG 序列，你的 RNG 已注入化，改造可控）。

为什么它属于「进度」而非「炫耀」：排行榜把「最高深度打完」变成「我的分数还有提升空间」——上限从设计者定死的数字，变成「别人做到过的事」。这是唯一不需要任何新内容的无限进度。

风险：云榜 = 后端成本，先本地榜。种子榜要防「种子世界被解出最优 build」——这是 feature 不是 bug：最优解公开反而制造「所有人都能挑战极限」的社区话题。
实现成本：低（本地榜）/ 中（云榜 + 种子）
维度：比较进度
进度感贡献：★★★★☆（无限上限，零内容消耗）
G6

蚀潮纪事 · 叙事碎片

TIDE CHRONICLE — LORE FRAGMENTS
FUN HYPOTHESIS「蚀月的真相，还差最后一片」——通关与特定条件解锁世界观文本，凑成编年史。

机制：24 片叙事碎片（对应 20 夜 + 深度 + 隐藏条件），通关第 N 夜解锁一片，特定深度/无伤/全图鉴解锁隐藏碎片。收集页以「蚀月编年史」时间线呈现。为什么有效：叙事是「有限但不可预测」的收集——玩家不知道还剩几片，也不知道下一片讲什么，这个「未知」本身就是进度钩子（区别于可见的成就列表）。

风险：文案成本被低估是常态。对策：先写 8 片核心（终焉 + 深度 9 + 隐藏），其余碎片化短句——碎片系统允许「一句话也算一片」。
实现成本：低（文案为主，UI 复用图鉴）
维度：发现进度
进度感贡献：★★★☆☆（长尾收集，适合后期内容）
G7

隐藏夜 · 蚀月回廊

SECRET NIGHT — ECLIPSE CORRIDOR
FUN HYPOTHESIS「这个条件达成后……怎么多了一夜？」——隐藏夜是发现式惊喜，一次就值回票价。

机制：特定月相 + 特定条件触发（如「满月之夜无伤通关 12 夜」）→ 终焉前插入隐藏夜「蚀月回廊」：全新敌型组合 + 专属 Boss + 专属回响奖励（×2 结算）。不告知条件（图鉴里给模糊提示：「有些夜晚，只在血月之下开门」）。

风险：隐藏条件太苛刻 → 社区考古成本高；太简单 → 没有发现感。条件设计为「中高级玩家自然路过」——不是要求极限操作，是要求「尝试了不同月相」。做 1 个验证假设，别一口气做 3 个。
实现成本：中（一个新夜 + 触发系统）
维度：发现进度
进度感贡献：★★★☆☆（惊喜值高，但一次性）
G8

武器熟练度 · 月蚀形态

WEAPON MASTERY — ECLIPSE FORMS
FUN HYPOTHESIS「这把弩我用了二十局，它该记得我了」——用过的武器累积熟练度，解锁月蚀形态（视觉 + 小被动）。

机制：每把武器按「携带局数 × 击杀数」累积熟练度，3 档形态：初蚀（100 击杀 · 无）→ 蚀染（500 击杀 · 小被动如攻速 +4%）→ 月蚀（1500 击杀 · 专属特效 + 图鉴条目）。13 把 × 3 档 = 39 个目标。为什么对这个游戏特别契合：5 武器上限 + 商店武器池 = 玩家天然会换 build——熟练度把「换 build 的沉没成本」变成「新目标」，鼓励广度而非重复最优解。

风险：熟练度只奖励老武器 → 新武器无人问津。对策：新武器首局给 1.5× 熟练度加成（尝鲜奖励）；形态被动必须小于月契树同级收益，防止两套成长叠加失控。
实现成本：低-中（计数 + 形态配置 + 图鉴）
维度：熟练度
进度感贡献：★★★★☆（39 个目标，换 build 有奖励）
G9

每周蚀潮 · 周常规则

WEEKLY TIDE — ROTATING RULES
FUN HYPOTHESIS「本周敌人死后会分裂——上周那套 build 不灵了」——周常规则让 meta 每七天换血一次。

机制：每周一刷新一个全局规则（规则表 6–8 条轮转：分裂潮 / 双 Boss / 金币翻倍敌人数翻倍 / 投射物减速……），叠加月相与每日通缉形成三层时间节奏（日 = 月相 + 通缉，周 = 蚀潮规则）。周常规则改变最优 build——上周的毕业构筑这周可能不是最优，meta 每七天动一次，重玩性自动刷新。

风险：规则若只是数值浮动 → 第三周无感。每条规则必须改变一种决策（分裂潮逼你优先范围伤害，金币翻倍逼你激进抢钱），否则就是换皮数字——这条红线与上轮 F 一致，两条时间轴共用一条设计准则。
实现成本：低（规则表 + 周刷新）
维度：时间性

推荐组合包：按投入分三档

别 15 个一起做。三档，每档是一个完整闭环，先跑通再扩。

档位 1 · 快赢（约 1–2 周）

G2 + C + G8：把已有资产点亮

目标：让玩家「看见」进度
  • G2 月相显性化：HUD 亮出月相效果
  • C 每日通缉令：每天一个 Boss 目标
  • G8 武器熟练度：39 个形态目标
为什么：三件全是「现有资产 + 目标化」，零新美术、零新曲线，但立刻产生「每天有目标、用过的武器有进度」。给玩家一个「你还有事做」的即时信号，验证进度感假设的最小闭环。
档位 2 · 主轴（约 3–5 周）

A + B + G3 + G4：进度货币与目标体系

目标：任何一局都不白打
  • A 蚀月回响：跨局货币 + 月契树（五杠杆节奏）
  • B 蚀之契约：自选挑战 × 回响倍率
  • G3 远征纪事 + G4 流派图鉴：限制 run 与 build 目标
为什么：档位 1 是信号，档位 2 才是回路——货币把「任何一局」都变成资产，契约让难度变成赌注，纪事与流派把重玩变成收集。G2/C 的回响出口也接在这里（每日通缉给回响）。
档位 3 · 纵深（约 6–10 周）

G1 + D + G5 + G6/G7：内容与上限

目标：上限无限化
  • G1 武器进化：先 3 对，品类招牌目标
  • D 无尽蚀潮 + G5 占星榜：无限上限 + 比较
  • G6 纪事碎片 / G7 隐藏夜：发现式长尾
为什么：档位 1+2 已经回答了「为什么继续打」，档位 3 回答「打完以后呢」——进化给单局终极目标、无尽给无限上限、排行榜给比较意义、碎片给收集长尾。这是「最高深度打完」之后的世界。
