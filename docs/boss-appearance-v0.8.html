Moonlight Chronicle · Boss Appearance v0.8

同样的立像，
这次配得上蚀月之主的身份。

精细配方全面升级：体积渐变（4+ 层 stop）、高光与暗部、纹样系统（浪纹/鳞甲/羽毛/符文）、环境氛围（光晕/粒子/地形）。十个立像全部重绘，动效层次从 2-3 个提升到 5-8 个。

体积 · 不再是剪影

主体全部用 4+ stop 径向/线性渐变塑形，配合独立高光 path 与暗部 path——立像从「平面贴图」变成「有体积的存在」。

纹样 · 身份的肌理

每位 Boss 一套纹样系统：浪纹 / 壳纹 / 熔岩鳞 / 闪电羽 / 咒文环——材质细节是身份的指纹。

氛围 · 它站在哪

背景光晕（主题色）+ 环境粒子 + 地面光影——立像不再悬空，它站在自己的世界里。

动效 · 分层活着

主体呼吸 / 细节脉动 / 粒子漂移三层动效，近看有细节，远看有节奏。
