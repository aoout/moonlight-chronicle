Fun Hypothesis（本报告的唯一地基）

蚀月远征好玩的升级体验 = 玩家每一次升级都在「赌命运」，而且「赌得起」——运气可见、可影响、可对冲。抽卡不是惩罚，是决策。

现状一句话诊断

现有升级祝福是 17 张纯数值卡 3 选 1（blessings.json，权重抽取），月相是现实时间被动 buff（moon_phase.ts）。两个系统各玩各的，互相零交互。祝福选择是算术不是策略，月相是天气不是资源。升级决策在单局第 10 分钟前后死亡——此后选什么不再重要，而系统没有给玩家任何干预命运的手段。

四条设计支柱，后续每个提案都要过这四关：

壹
决策完整性

每次升级必须产出「信息完整的决策」——知道选项、代价、赌注。

贰
运气代理

运气是资源不是天气：可赚、可花、可对冲、可保底。

叁
构建方向

单局内能形成 build：羁绊 / 系别 / 赌约互相咬合。

肆
跨局痕迹

选择在跨局尺度留痕，让「这局没白打」成立。

推荐结论（先看这里）

不推荐 8 个提案全上——那是一场范围膨胀的灾难。推荐走 提案 H 整合蓝图：以「命运之轮 v2」为骨架，按 A（轮盘仪式感）→ F（幸运货币化）→ D（月相干预）→ E（纠错回响） 四阶段渐进落地，每阶段独立 playtest、预定义失败信号。理由与阶段划分见下文第 3 章。

0.1 · 祝福系统现有构成（blessings.json 全量盘点）

档位数量权重区间构成典型代表
common 寻常812 → 67 纯数值 + 1 复合月髓 +12 生命 / 锋芒 +2 攻击 / 财源 +20% 金币
epic 非凡85 → 36 纯数值 + 2 百分比裂痕 +25% 暴伤 / 余影 +1 投射物 / 时弦 +4% 冷却
legend 命运12双属性命运之契：幸运 +30%、攻速 +10%

三个结构性事实：没有任何负面词缀（零风险）、没有任何祝福间联动（零构建）、幸运只有一条祝福产出且用途感知极弱（本应是命运货币，现在只是隐性概率）。

0.2 · 月相系统现有构成

相效果性质
新月闪避 +25%全局被动 buff，按现实时间（朔望月 29.53 天）自动轮转，玩家零干预。
娥眉攻击 +15%、经验 +15%
上弦暴击率 +12%、攻速 +12%
盈凸攻击 +10%、范围 +10%、投射物 +1
满月攻击 +25%、暴伤 +25%
亏凸生命 +15%、伤害转化护盾
下弦冷却 -15%、受击生成护盾

这个系统的存在感问题是致命伤：玩家不知道、不关心、不围绕它构建。它却是全项目世界观契合度最高的机制——「守月人守护的月亮」——现状等于把最好的主题素材做成了天气。

0.3 · 问题清单（按严重度排序）

级别问题证据 / 推演
P0决策死亡3 选 1 无联动无取舍，纯数值比较。玩家第 3 次升级起进入肌肉记忆，第 10 分钟起「选什么」不再重要。
P0运气零代理权重抽取纯随机：无 reroll、无倾向、无保底、无补偿。抽到传说 = 中彩票，抽不到 = 罚站。玩家对命运零控制权。
P1系统孤岛blessings / moon_phase / luck / 金币四条线互不咬合。一个「月辉祝福只在满月夜权重翻倍」的规则都不存在。
P1月相浪费现实月相是稀缺主题资产，却做成纯天气。它本该是「命运之轮」最好的实体化身。
P2无长线目标没有构建方向、没有羁绊、没有跨局记忆。升级选择不构成「我的 build」，肉鸽的「这一把」没有指纹。

A

命运轮盘

升级从「三张卡」变成「亲手拨动的蚀月轮盘」+ 月契对冲经济
已实现 · 2026-08-08仪式感运气对冲UI 层为主
Fun Hypothesis：升级的爽点 = 亲手转动命运轮的仪式感 + 用月契对冲坏运气的掌控感。抽卡从「被审判」变成「我下注」。

实现注记：本提案已按用户定制版落地（feat/fortune-wheel 分支）。差异：轮盘 12 格 = 11 祝福（18 选 11，权重 + 幸运修正）+ 1 蚀格；新命运祝福「蚀月壁垒」（+18 生命 +2 护甲）；命运之契攻速 18%、裂痕暴伤 30%；幸运不再影响金币/经验，改为修正 epic/legend 权重；四操作 = 拨动(+1 月契)/强化(2)/踢格(3)/月轮(5，10×攻击固定伤害+回血至 80%)。

核心机制
  • 升级弹出 12 格蚀月轮盘：common ×6 / epic ×3 / legend ×2 / 蚀格 ×1（蚀格 = 空转，获得少量金币补偿而非祝福）。
  • 拨动（默认）：随机落点，权重仍受 luck 修正（见提案 F）。
  • 锁格：花 1 枚月契，把当前停驻格子的祝福钉住，下次转动必落该格。锁 legend 格是核心赌注——锁了就不能再转。
  • 偷看：花 2 枚月契，预览下一轮盘的 3 个落点（信息博弈，可据此决定锁不锁）。
  • 清蚀：花 2 枚月契移除本轮蚀格，代价是本轮不再产出金币补偿。
月契经济（Sources / Sinks）
  • 产出：精英击杀 +1 · 宝箱 +1 · 完成赌约 +2（提案 C 联动）· 金币购买 50g/枚，每夜限 2 枚。
  • 消耗：锁格 1 · 偷看 2 · 清蚀 2 · 回响台费用之一（提案 E 联动）。
  • 预期平衡：单局月契收入 4-6 枚，支出弹性 2-5 枚——永远不够花，永远够赌一次。[PLACEHOLDER · 依据：按 20 分钟单局、2-3 个精英波次估算；若实测精英密度翻倍，产出砍半]
图 A-1 · 蚀月轮盘示意（12 格）+ 月契操作清单。格色：深蓝=common / 紫=epic / 金=legend / 红=蚀格。
玩家新决策
  • 这轮 转 or 锁？锁了 legend 就放弃了轮盘的其他可能。
  • 月契 花在哪：锁格保底 vs 偷看信息 vs 清蚀避险——资源永远不够，取舍即策略。
  • 轮盘停在不想要的格子时：认了（省月契）还是 清蚀重转（烧月契）？
世界观咬合（记手录联动）
  • 轮盘文案：「蚀月之下没有免费的命运。第一个守月人偷看过一次轮盘，从此轮盘记住了他的手。」
  • 累计转动 10 次解锁深层 lore：轮盘侧面的蚀刻其实是一张星图，指向银湾。
  • 蚀格补偿文案：「月亮收走了祝福，留下几枚铜钱。」
失败信号（playtest 前定义，测前先立）
A-1玩家整局不消费月契（经济死亡：资源无价值）→ 调 sink 定价或产出节奏。
A-2玩家永远只锁 legend（对冲过头，惊喜消失，轮盘退化成商店）→ 锁格加次数上限或锁格后轮盘难度上调。
A-3测试者狂点跳过转动动画（仪式感失败）→ 动画压到 0.8s 以内或允许跳过但给「快转」音效补偿。
实现影响（点开）
LevelUpPanel 重构成轮盘视图；新增月契资源（persistence 扩展）；CONFIG.RNG_LEVERS 集中轮盘权重；祝福数据复用现有 blessings.json。风险：动画帧与暂停逻辑耦合，需防卡死（轮盘转动期间锁输入）。
B

祝福羁绊 · 六系盟约

升级从「一张张捡」变成「凑一套」——同系 2/3/4 件解锁套装效果
构建方向升格进化数据层为主
Fun Hypothesis：升级的爽点 = 「我在凑一套，不是在一张张捡」。羁绊成型的那一瞬间，之前所有单张的选择都有了意义。
核心机制
  • 17 个祝福打上 六系标签（月之民六约）：月辉（攻/暴击）· 蚀影（生存/吸血）· 星火（投射物/范围）· 霜华（减速/控制，需新增控制祝福）· 流金（金币/经验）· 命脉（回血/护甲）。
  • 同系集齐 2/3/4 件 解锁羁绊。示例（月辉系）：2 件 攻速 +8% → 3 件 弹道 +1 → 4 件 「月辉连击：暴击后下一次攻击必爆」[PLACEHOLDER]。满羁绊给的是机制不是数值。
  • 升格进化：同系集齐 3 件时，低阶祝福免费升格（b_atk → b_atk2，锋芒 → 破晓之锋）。
  • 权重偏移：选定某系 1 件后，同系祝福出现权重 ×1.35 [PLACEHOLDER · 依据：Hades duo boon 的定向手感；若偏移过大玩家会锁死单系，需下调]。
数值设计（羁绊表草案）
系2 件3 件4 件
月辉攻速 +8%弹道 +1暴击后下击必爆
蚀影吸血 +3%濒死时 3s 无敌击杀回复 5% 生命
星火范围 +8%投射物 +1弹射 +1 次
霜华减速效果 +20%减速敌人受击 +15%冻结 1.5s
流金金币 +25%精英必掉宝箱商店 8 折
命脉生命上限 +8%护甲 +3每秒回血 +1% 上限

全部 [PLACEHOLDER]，数值档位遵循「2 件数值 / 3 件机制化 / 4 件质变」原则——质变不堆数值，否则数值爆炸。

玩家新决策
  • 追系 or 分系：专注月辉冲 4 件质变，还是撒网等什么来什么？
  • 成型窗口：羁绊成型前是数值真空期——你愿意为质变忍受几轮弱选择？
  • 拆系成本：选了 2 件月辉后再看到传说蚀影，拆不拆？
世界观咬合
  • 六系 = 蚀理院失传的《六约残卷》：辉约、影约、火约、霜约、金约、生约——图鉴新增一页「盟约进度」。
  • 升格文案：「同一条盟约下的两种誓词，本就该是同一句话。」
  • 与记手录联动：满羁绊次数计入「相伴」，解锁深层 lore。
失败信号
B-1所有人只追月辉/星火（系间失衡）→ 逐系比对 DPS 贡献，弱势系给机制补偿。
B-2羁绊触发无感（数值太低或反馈缺失）→ 触发时加音效 + 飘字 + 屏幕边缘辉光。
B-34 件羁绊太远没人凑（节奏错误）→ 单局 20 分钟内应可稳定达成 1 个 3 件羁绊，这是节奏锚点。
实现影响（点开）
blessings.json 增加 "tag" 字段；新增羁绊配置表 src/config/bonds.ts；升格逻辑挂在 apply 之后；权重偏移改 pickBlessings 的采样权重。注意：羁绊触发依赖事件总线（击/暴/濒死），需核对现有事件覆盖。
C

命运赌约

带诅咒的超模祝福 + 倒计时猎杀令——拿未来换现在
风险回报传说补偿新祝福类型
Fun Hypothesis：升级的爽点 = 「我拿未来换现在」。赌赢了很爽，赌输了也是故事——它把失败从挫败变成叙事。
核心机制
  • 新祝福类型 赌约（curse）：负面诅咒 + 超模正面。
    • · 月蚀之约：攻速 +40%，但每 10s 损失 2% 最大生命 [PLACEHOLDER]
    • · 饮鸩之契：攻击 +50%，吸血 -100% [PLACEHOLDER]
    • · 渎月之誓：经验 +60%，但升级不再恢复生命 [PLACEHOLDER]
  • 倒计时赌约（猎杀令）：接令后 90s 内击杀 300 蚀物 → 成：获传说祝福；败：失去下一次升级 [PLACEHOLDER]。
  • 赌约祝福必出 legend 级数值（正面是普通祝福的 1.8-2.5 倍），否则没人接。
设计红线（这条提案最怕什么）
  • 惩罚必须可见可算：诅咒写在卡面上，玩家在接之前知道全部代价——决策完整性是支柱一。
  • 不允许即死：赌约负面只能制造压力，不能制造「无法预防的暴毙」。2% 生命流失可被回春/吸血对冲，这是可解构的，不是天罚。
  • 必留解约出口：回响台（提案 E）可支付月契解除诅咒——「赌徒永远有再赌一次的权利」。
玩家新决策
  • 接不接？月蚀之约对吸血 build 是白赚，对无回复 build 是慢性死亡——构建相容性成为决策。
  • 现在接还是等 build 成型再接？猎杀令接早必输，接晚白接。
  • 用什么对冲：诅咒可被祝福/道具/月相（亏凸护盾）抵消——围绕诅咒构建也是构建。
世界观咬合
  • 赌约 = 蚀月与守月人的买卖：「月亮从不免费，蚀物是利息。」
  • 猎杀令文案：「蚀潮欠了你九百条命，现在它们来还。」
  • 赌约胜负计入命运记忆（提案 G）：「你赢过月亮的赌，月亮记着。」
失败信号
C-1赌约无人接（回报/风险失衡）→ 调正面倍率；先做纸面模拟再上 build。
C-2接了必输（猎杀令数值不可达）→ 用历史击杀数据校准 90s/300 蚀物。
C-3惩罚导致直接暴毙（负反馈过重）→ 所有诅咒加「解除窗口」：代价可被后续操作对冲。
实现影响（点开）
blessings.json 增加 "curse" 与 "timer" 字段；新增猎杀令任务追踪（复用成就系统的计数管道）；失败惩罚 = 跳过下次升级的 hook。风险：诅咒 tick 与战斗暂停逻辑需统一时钟。
D

月相干预

把现实月相从「天气」变成「策略资源」——守月人第一次骗过月亮
世界观爆点月尘资源利用现有基建
Fun Hypothesis：月相从被动天气变成可拨动的策略资源——玩家第一次对月亮有话语权，而「骗过月亮」本身就是世界观里最大的禁忌。
核心机制
  • 新资源 月尘：BOSS 击杀 +3 · 通关奖励 +2 · 精英波次稀有掉落 +1 [PLACEHOLDER]。
  • 拨月：花 2 月尘，把当前月相推进或回退 1/8（方向自选）——为下一个 BOSS 夜调到想要的相位。
  • 月蚀之夜（主动）：花 5 月尘，人为制造新月（闪避 +25% 保命相），代价：该夜蚀物强度 +15% [PLACEHOLDER]。
  • 月相倾向祝福：祝福带相位标签，特定相位下出现权重 ×2（如满月夜「裂痕」暴伤权重翻倍）——月相从此影响 build 走向。
玩家新决策
  • 这一夜拨到哪一相：为保命（新月/亏凸）还是为 build（满月）还是为清怪（娥眉）？
  • 月尘攒着（等满月 boss 战）还是花掉（每夜微调保命）？
  • 主动制造月蚀之夜：用强度换闪避，赌自己走位值不值？
  • 月相与祝福联动后：等相位还是改相位？——顺命运者等，逆命运者拨。
图 D-1 · 现实月相八相。满月（金框）与残月（红框）是「月相倾向祝福」的锚点相位。
世界观咬合（核心卖点）
  • 守月人誓词里的禁忌：「月亮可以生病，但不能被骗。」拨月 = 打破誓词——系统本身就是叙事。
  • 拨月动画：星图上的月亮被手指推回一格，星轨发出断裂声。
  • 月蚀之夜文案：「今晚没有月亮。今晚只有你。」
风险与取舍（设计师自辩）
  • 破坏浪漫：现实月相联动是「你的月亮」的浪漫设定。干预会让玩家永久无视现实时间。
  • 折中方案：拨月只能单向推进（时间是单行道），回退需要双倍月尘——保留「现实流逝」的质感，干预有限度。
  • 数据护栏：月相倾向祝福只做「权重 ×2」不做「仅此相位出现」——玩家错过也不至于彻底失去。
失败信号
D-1月尘囤着不用（资源无价值）→ 调 sink 定价，或给月尘加「过期作废」制造消费压力。
D-2所有人只调满月（相位不平衡）→ 满月权重下调，弱势相位给机制补偿。
D-3现实月相存在感归零 → 拨月成本提高到「不能每夜都拨」，现实相位仍是默认态。
实现影响（点开）
moon_phase.ts 加干预层（当前相位偏移量）；新增月尘资源；祝福表加 "phaseBoost" 字段；拨月 UI 复用商店面板。现有 moon_phase 是纯函数，改动面可控。
E

命运回响

重塑 / 升格 / 拆解——给中期走歪的 build 一次「重铸命运」的机会
纠错机制记手录联动商店扩展
Fun Hypothesis：中期发现 build 走歪了，玩家要的不是「这把废了」，而是一面可以砸掉重来的回响台——纠错能力本身就是深度。
核心机制（回响台，商店子功能）
  • 升格：低阶 → 同系高阶（b_atk → b_atk2），50g + 1 月契 [PLACEHOLDER]。把前期投入保留下滑。
  • 变异：随机换成同稀有度另一祝福，30g（赌——命运主题的一致性）。
  • 拆解：传奇祝福 → 2 个普通祝福 + 1 月契（回收：传奇不适合当前 build 时的退出通道）。
  • 解约：支付 2 月契解除赌约诅咒（提案 C 的出口，设计上必须存在）。
价格 rationale（纠错的成本哲学）
  • 纠错必须贵：比「重新选对」贵，但比「重开一局」便宜。50g ≈ 2 个普通宝箱的产出 [PLACEHOLDER]。
  • 纠错不能无限：每次使用回响台，该局价格 ×1.5（2 次后封顶）——「命运可以重来，但不能反复无常」。
  • 目的：让纠错成为一次性的战略决策，而不是随意重 roll 的后悔药。
玩家新决策
  • 投资纠错 vs 带着烂 build 打完——金币花在纠错还是花在商店装备？
  • 拆传奇值不值：拆掉不合适的传说换 2 个普通 + 月契，还是硬着头皮围绕它转型？
  • 什么时候用掉「唯一一次免费升格」？
世界观咬合
  • 记手录联动：重塑第 10 次解锁深层 lore——「器识其主，也识其悔。」
  • 回响台文案：「月亮听过你所有的选择，包括你反悔的那几次。」
  • 拆解动画：传奇祝福碎成月光，重新凝成两粒微尘。
失败信号
E-1重塑永远不值得（数值错误）→ 用 3 局试玩收集「用与不用」的使用率，低于 30% 即降价。
E-2玩家频繁重 roll（决策失去后果）→ 强化价格递增，让「重来」成为昂贵动作。
实现影响（点开）
商店新增回响台 Tab；升格/拆解复用 blessings apply/remove（需新增 remove 语义，当前 apply 无逆操作，注意状态回滚）；价格递增状态存 run 级。

福运经济

幸运从隐性概率变成「命运的存款」——可攒可花，双用途货币
货币化重构通胀治理系统级
Fun Hypothesis：幸运不是属性，是存款。攒着拉高稀有度是复利，花掉保底 reroll 是保险——「命运的复利」第一次可操作。
核心机制
  • 命运值可视化：HUD 显示当前 luck 换算的「命运值」（1% luck = 1 点命运值 [PLACEHOLDER]）。
  • 被动用途：命运值越高，祝福稀有度权重越高（每 +10 点，legend 权重 ×1.5 [PLACEHOLDER · 依据：指数衰减采样；需 Monte Carlo 验证对「每局 legend 期望数」的影响]）。
  • 主动消费：5 点 = 1 次 reroll（换一批 3 选 1）· 8 点 = 1 次锁卡 [PLACEHOLDER]。
  • 获取：b_luck 祝福（+15 点）、b_legend（+30 点）、月相上弦、道具、商店 100g 购 +5 命运值。
经济模型（Sources / Sinks / 通胀护栏）
项数值
单局命运值产出预期≈ 30-45 点
reroll / 锁卡单次5 / 8 点
通胀检测指标命运值/分钟 > 2.5 触发平衡 pass [PLACEHOLDER]
legend 权重修正×1.5 / 每 10 点，上限 ×4 [PLACEHOLDER]

通胀定义：命运值/分钟持续超过阈值 → 全员 legend 满配，稀有度失去意义。这是本系统的「坏掉长什么样」。

玩家新决策
  • 攒 vs 花：攒着拉高全局稀有度（复利）还是花掉保底单次（保险）？
  • 命运值的两种消费（reroll 换广度 vs 锁卡换确定性）在不同 build 阶段价值不同。
  • 与提案 A 联动：轮盘的「偷看/锁格」也可用命运值支付——两条经济线互为备胎。
世界观咬合
  • HUD 命运值图标 = 一枚缓缓转动的古币，正面刻月，背面刻蚀。
  • 文案：「月背的老人们说，运气是存得下来的。存到满月那天，够买一场好梦。」
失败信号
F-1命运值通胀（后期人人 legend 满配）→ 通胀指标 > 2.5 点/分钟时下调产出或上调 sink。
F-2命运值太贵无人消费 → reroll 使用率低于 25% 时降价。
F-3数值显示与体感不符 → luck 的底层语义与 HUD 展示必须同一来源（stats.ts 已集中），避免两套真相。
实现影响（点开）
luck 语义扩展 + HUD 命运值组件；稀有度采样权重接入 luck 修正；消费 hook 挂在 pickBlessings 层。风险：luck 现被掉落率复用，需确认 luck 的既有消费点，避免双语义打架。
G

命运记忆

跨局纹章 + 命运残响——月背记得你每一次选择，包括你没选的
肉鸽 meta选择留痕持久化扩展
Fun Hypothesis：「这局没白打」——单局的选择在跨局尺度留下痕迹，肉鸽的每一把都有指纹。
核心机制
  • 单局结算记录命运轨迹：祝福系别分布、赌约胜负（提案 C）、拨月次数（提案 D）。
  • 生成 命运纹章（1 枚）：下局开局小 buff。如「上局月辉系 ≥3 件 → 开局攻速 +5%」「上局猎杀令失败 → 本局猎杀令时限 +15s」[PLACEHOLDER]。
  • 纹章最多叠 3 层，同纹章不叠加（防刷，防「为了叠纹章故意摆烂」）。
  • 命运残响：本局未选中的祝福，下局出现率 +15% [PLACEHOLDER]——「你拒绝过的命运还会回来敲门」。
玩家新决策
  • 这局要不要为下局投注？追一个不完整的系，赌它产出纹章？
  • 纹章与残响制造跨局连续性：连续三局围绕同一系构建 = 一条「命运弧线」。
  • 风险自辩：跨局设计有稀释单局体验的风险——纹章 buff 必须弱（≤5%），它的价值在「痕迹感」不在「强度」。
世界观咬合
  • 记手录机制的直接延伸——「月背记得你每一次选择。它甚至记得你没选的。」
  • 纹章在结算界面以「月面刻痕」形式显示，随局数累积成一面碑。
与现有系统的咬合
  • 成就系统已有跨局计数基建（a_kill_100 等）——命运轨迹复用同一管道。
  • 「残响池」防垃圾循环：残响只加出现率，不加权重——垃圾祝福不会滚雪球（权重仍是主控）。
失败信号
G-1纹章 buff 无感 → 结算界面纹章反馈不足；先强化「展示」再谈数值。
G-2玩家为叠纹章故意摆烂 → 纹章叠加衰减（第 2/3 层效果减半）或加次数上限。
G-3残响导致垃圾祝福越滚越多 → 残响只对「同系 ≥2 件」的系生效，不全局生效。
实现影响（点开）
结算记录 → 持久化（复用 hands.ts 的 localStorage 模式）；纹章 buff 注入开局 Player；残响池进 pickBlessings 权重修正。跨局状态独立于单局状态，架构上低风险。

推荐路线——A+F+D+E 组合拳，四阶段渐进落地，每阶段独立 playtest
推荐分阶段完整系统
Fun Hypothesis（整合版）：升级体验 = 拨动命运轮盘（仪式感）× 用命运值干预概率（运气代理）× 把月相调成自己的主场（策略纵深）——三层的「命运」互相咬合，每次升级都是完整决策。
为什么

8 个提案全上 = 范围膨胀灾难。H 只取四个核心：A 解决最痛的「决策死亡 + 运气零代理」（UI 层为主，改动面最小）；F 让 luck 变成真资源（系统级但风险可控）；D 吃满世界观红利（复用 moon_phase 现有基建）；E 提供纠错出口（让前三个系统的冒险「赌得起」）。B/C/G 作为后续可选扩展，不阻塞主线。

一句话收尾

现在的升级系统不是「不够丰富」，是玩家对命运没有任何代理权。先给代理权（A+F），再给纵深（D），最后给兜底（E）——丰富是手段，代理权才是那枚月亮。
